- 6DF3 receptor contacts were computed from the downloaded coordinates using a 5.0 Å heavy-atom distance cutoff. IL-24 is chain C; IL-22R1 is chain L; IL-20R2 is chain H.
- Literature T198 maps provisionally to project residue T173 by the mature-chain offset (52–206 -> 27–181). Exact sequence confirmation remains required.
