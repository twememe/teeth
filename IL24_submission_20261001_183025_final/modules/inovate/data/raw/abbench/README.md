We introduce AbBiBench (Antibody Binding Benchmarking), a benchmarking framework for optimizing antibody binding affinity. This dataset contains the sequences of mutants, experimentally measured affinity values, and the structures of antigen-antibody complexes.
Mutant structure files for AbBiBench dataset is available at https://zenodo.org/records/16557372
